⚙ GitHub 설정

GitHub 계정·저장소·브랜치·경로·토큰을 입력하는 설정창을 엽니다. 처음 한 번만 입력하면 됩니다.

📤 백업
⬇ db.json 다운로드

현재 표 내용을 db.json 파일로 로컬에 저장합니다. GitHub 저장이 안 될 때를 대비한 백업/비상용입니다.

엑셀 업로드 형식: 첫 행은 머리글(업무구분, 분야, 쟁점, 실적내용)로 두고, 그 아래에 데이터를 입력한 .xlsx/.xls 파일을 사용하세요. 업무구분 값은 "소송"/"자문", 분야 값은 아래 9개 분야 명칭과 정확히 일치해야 목록에서 올바르게 선택됩니다. 분야가 2개 이상이면 한 칸에 건설행정, 건설환경 처럼 쉼표(,)나 슬래시(/)로 구분해서 적으면 표에서 해당 분야가 모두 함께 표시됩니다. 쟁점, 의뢰인유형은 선택 항목이며, 비어 있어도 됩니다. 수임번호 등 위 5개 항목(업무구분·분야·의뢰인유형·쟁점·실적내용)에 해당하지 않는 다른 열은 자동으로 무시되어 표에 나타나지 않고 저장되지도 않습니다. 의뢰인유형은 user.html의 의뢰인 업종 키워드 검색에도 함께 사용됩니다. 표에 나오는 업무구분·분야·의뢰인유형·쟁점·실적내용은 엑셀/JSON에 입력된 내용을 그대로 보여주는 화면이며, 표에서 직접 수정할 수는 없습니다. 수정이 필요하면 엑셀 파일을 고친 뒤 다시 불러와 주세요.
GitHub → Settings → Developer settings → Fine-grained tokens에서, 이 저장소 하나만 선택하고 Contents 권한을 Read and write로 지정한 토큰을 발급해 입력하세요. 토큰은 저장소에 쓰기 권한을 가지므로 타인과 공유하지 마세요. "이 브라우저에 저장"을 체크하지 않으면 탭을 닫을 때 토큰이 사라집니다.
